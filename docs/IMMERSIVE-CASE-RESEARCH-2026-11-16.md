# Immersive case study references

| Interaction | Source inspected | License and implementation decision |
| --- | --- | --- |
| Scroll-linked perspective | [Codrops Scroll3DGrid implementation](https://github.com/codrops/Scroll3DGrid/blob/69718a2eff87b32ab19764b3a6d7b3773dab6af3/js/index.js) uses perspective, GSAP timelines with ScrollTrigger scrub ranges, and Lenis. [Chrome’s codelab](https://codelabs.developers.google.com/scroll-driven-animations) describes element entry ranges for native CSS timelines. | [Codrops MIT license](https://github.com/codrops/Scroll3DGrid/blob/69718a2eff87b32ab19764b3a6d7b3773dab6af3/LICENSE) and [codelab Apache 2.0 license](https://github.com/GoogleChromeLabs/io23-scroll-driven-animations-codelab/blob/2dab7400e83553ba21ebf13e06b8d1b5538cd652/LICENSE). ScrollTrigger provides scrub, pinning, and timeline coordination. Its [source header](https://github.com/greensock/GSAP/blob/5e6c35ff8eedea12d4f229129def635277d8b0f2/src/ScrollTrigger.js#L1-L12) points to [GSAP’s standard license](https://gsap.com/community/standard-license/). The existing six tiles only need a finite entry range, so CSS view timelines and 3D transforms keep the scroll path native without JS scroll reads. |
| Fluid displacement | [Codrops SVGImageHover filter](https://github.com/codrops/SVGImageHover/blob/333643f9c380758b6f8f8f408ff50d17fba597e5/index2.html) feeds turbulence into a displacement map. Its [script](https://github.com/codrops/SVGImageHover/blob/333643f9c380758b6f8f8f408ff50d17fba597e5/js/demo2.js) tracks pointer velocity and updates the filter. | No explicit repository license file was found at the reviewed revision. Implementation uses original code and standard SVG filter primitives. A small procedural cover layer allows the effect to keep source phone images unfiltered. Constant noise frequency and event-driven amplitude avoid a continuous shader or a WebGL library. |
| Magnetic affordance | [Codrops MagneticButtons implementation](https://github.com/codrops/MagneticButtons/blob/b2ee8ac9cd561e13198335cca5684fe1c31d543c/src/js/demo1/buttonCtrl.js) measures pointer distance from a control and interpolates its translation. | [MIT license](https://github.com/codrops/MagneticButtons/blob/b2ee8ac9cd561e13198335cca5684fe1c31d543c/LICENSE). A damped spring moves the inner label. The outer link keeps its native focus and click geometry. Frames end when the spring settles. |

Phase 5 uses original JavaScript, CSS and SVG markup. No upstream code, images, fonts, or runtime packages are included. Native timelines are gated by feature detection and input preference. Visitors on browsers without CSS view timelines see the same six flat tiles and original comparison controls.
