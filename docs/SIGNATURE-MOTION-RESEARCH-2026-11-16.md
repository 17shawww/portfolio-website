# Phase 4 signature motion references

Source and license review, November 16, 2026. The portfolio implementation uses its own assets and native browser code. No third-party code, artwork, fonts, or runtime packages were imported.

| Effect | Implementation inspected | Dependencies and license | Portfolio decision |
| --- | --- | --- | --- |
| Ink particles | [Interactive Particles](https://github.com/brunoimbrizi/interactive-particles/blob/efe300f9cd2b976da377ed43e9f50662fb575bf7/src/scripts/webgl/particles/Particles.js) reads image pixels and uses instanced quads. Its [touch texture](https://github.com/brunoimbrizi/interactive-particles/blob/efe300f9cd2b976da377ed43e9f50662fb575bf7/src/scripts/webgl/particles/TouchTexture.js) feeds local displacement into the [vertex shader](https://github.com/brunoimbrizi/interactive-particles/blob/efe300f9cd2b976da377ed43e9f50662fb575bf7/src/shaders/particle.vert). | The [manifest](https://github.com/brunoimbrizi/interactive-particles/blob/efe300f9cd2b976da377ed43e9f50662fb575bf7/package.json) declares MIT. The reviewed root has no separate license file. The demo uses Three.js, GSAP 2 and GLSL tooling. | Sample the existing YP PNG with Canvas 2D. Bound the particle count and runtime, then restore the unchanged source image. |
| Kinetic type | [Codrops Repetitive Typography](https://github.com/codrops/RepetitiveTypography/blob/9bd910cadc638ac3a855690600eecf485504b6e1/src/js/index.js) phases character movement through clipped rows using a timeline. | [MIT demo license](https://github.com/codrops/RepetitiveTypography/blob/9bd910cadc638ac3a855690600eecf485504b6e1/LICENSE). The [demo manifest](https://github.com/codrops/RepetitiveTypography/blob/9bd910cadc638ac3a855690600eecf485504b6e1/package.json) lists GSAP, Splitting and imagesLoaded. | A temporary visual layer moves letters while regular semantic text keeps its original spacing. Web Animations handles one finite entrance. A short mask is reserved for two Home headings. |
| Work/case transition | [View Transitions Toolkit](https://github.com/GoogleChromeLabs/view-transitions-toolkit/blob/387d9f46da3fdfc1a2935309e380161f23fb4b26/src/navigation.ts) uses `pageswap` and `pagereveal` to identify the navigation pair. Its [feature detection](https://github.com/GoogleChromeLabs/view-transitions-toolkit/blob/387d9f46da3fdfc1a2935309e380161f23fb4b26/src/feature-detection.ts) distinguishes cross-document support from same-document support. | [Apache-2.0](https://github.com/GoogleChromeLabs/view-transitions-toolkit/blob/387d9f46da3fdfc1a2935309e380161f23fb4b26/LICENSE). The helpers are TypeScript. | Use browser snapshots for the existing card and case hero, following [Chrome's cross-document guidance](https://developer.chrome.com/docs/web-platform/view-transitions/cross-document). Keep the browser in charge of navigation and history. |

[GSAP core and its license header](https://github.com/greensock/GSAP/blob/5e6c35ff8eedea12d4f229129def635277d8b0f2/src/gsap-core.js) were checked against [Webflow’s current GSAP terms](https://gsap.com/community/standard-license/). The standard license permits website use and includes proprietary-notice and other restrictions. Native APIs cover the short stagger, bounded Canvas pulse and cross-document snapshots in this implementation. The portfolio adds zero package dependencies or third-party notices.
